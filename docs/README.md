# Documentation & Assets

このディレクトリはゲームプロジェクトのドキュメントと素材を格納する場所です。

## ディレクトリ構成

### `/assets/`
ゲーム内で使用する素材ファイル
- 画像・スプライト
- アイコン
- アニメーション
- サウンド

### `/design/`
デザイン資料とリファレンス
- ワイヤーフレーム
- UI/UXデザイン
- ゲームデザインドキュメント

### `/reference/`
参考資料とリソース
- 外部リンク集
- 技術リファレンス
- ガイドライン

## 使い方
- 素材を追加する際は、適切なカテゴリのディレクトリに配置してください
- ファイル名は分かりやすく、統一されたネーミング規則に従ってください
- 大きなファイルはGit LFSの使用を検討してください
