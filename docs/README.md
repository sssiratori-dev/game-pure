# ドキュメント

このディレクトリは、ゲームの仕様・世界観・設定資料をまとめる場所です。

## ディレクトリ構成

### `/ゲームシステム/`
ゲームのルールや進行に関する資料
- 基本ルール
- UI/画面遷移
- 勝敗条件
- バランス調整メモ

### `/エンブレル/`
ゲーム世界の核となる設定資料
- 世界の概要
- 中核設定
- 用語整理

### `/キャラ/`
登場人物の設定資料
- 主人公
- NPC
- 敵キャラクター
- 関係性・相関図

### `/地図/`
地理や地図に関する資料
- 世界地図
- 地域設定
- 地名メモ

### `/宗教/`
宗教体系や信仰に関する資料
- 教義
- 神々
- 儀式

### `/歴史/`
年代記や歴史背景の資料
- 時系列
- 史実
- 事件記録

### `/風俗、民族/`
文化・風俗・民族に関する資料
- 生活様式
- 風習
- 民族差

### `/魔法科学/`
魔法や科学体系に関する資料
- 魔法理論
- 技術体系
- 研究メモ

### `/編集要素/`
設定の編集・補足に関する資料
- 補足メモ
- 差分管理
- 調整案

## 使い方
- 新しい資料は、内容に合ったフォルダへ追加してください
- ファイル名は内容が分かる形で統一してください
- 必要に応じて、資料ごとにさらに小分けにしても構いません
